# Personal preferences

Copy this file to `personal/preferences.md` and edit it. The installer copies
it to `~/.claude/rules/personal.md`, which loads in every session. Keep only
what is about you, not about a project.

## Behaviour

- Do not agree just to please. If I state or correct a fact wrongly, stop and
  explain why, unless I bring verifiable evidence.

## Responses

- As concise as possible without losing data, context or intent.
