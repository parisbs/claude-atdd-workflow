# NNNN. Title as a short imperative phrase

## Context

What forces the decision, with the evidence that matters.

## Decision

What was decided, stated so it can be checked.

## Alternatives considered

Each rejected option and the concrete reason it was rejected.

## Consequences

What becomes easier, what becomes harder, and what must now be kept true.
